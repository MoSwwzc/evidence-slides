# Visual planning and variants

## Figure-first but not figure-only
Inspect original figures, source PPT media, tables and supplemental graphics before considering image generation. Use total-framework overview -> faithful crop/detail -> return-to-framework only when the zoom assists understanding. A data-driven chart can be the main composition without added decoration.

## Source-preserving treatments
Keep original scientific colors, axes, arrows and labels. Use whitespace, scale, positioning and native headline text to coordinate the figure with the theme. Crops must not remove needed captions, legend or conditions. Use original PNG/SVG/vector when accessible; otherwise render sufficient resolution. Do not recreate paper charts with ImageGen.

## Native PowerPoint objects
Prefer native text and tables for readability and editability. Use native arrows for simple logical relations, short timelines and notations. Avoid automatically turning every idea into a rounded card and every concept into a connected rectangle. Complex science assets deserve actual source images or generated independent visual objects.

## ImageGen gates
Generate an independent, conceptual, label-free object only when: (1) a slide has a specific explanatory need, (2) the material does not already include an appropriate visual, (3) host image-generation tools are available, (4) a rendered concept image does not pretend to be experimental evidence. State target object, view, realism, palette, background and placement. Inspect anatomy/molecular realism, gibberish text and misleading structure. Save with descriptive filename and embed; a prompt or plan alone does not count.

## Distinct full variants
Use a single fact and source ledger for every version. Variation can come from figure hierarchy, density, comparison layout, progressive zoom and spatial pacing. Do not vary sample counts, results or evidence limitations. Record per-version layout choices. Default variants: editorial (more evidence comparison) and visual (larger figures, fewer on-canvas words, richer notes). If there is only text, both versions can still vary through semantic typography and table/progression formats without decorative images.

## Theme
Neutral default is white background, dark text, restrained accent. Alternate presets may use dark backgrounds or color. A user's uploaded template overrides presets where faithful and technically feasible. Any logo must come from authorized supplied assets, never from generated imitation.
