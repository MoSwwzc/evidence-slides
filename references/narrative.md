# Narrative and content planning

## First produce a message, not a list of section titles
Answer: What does the audience need to understand? Which observation creates the problem? Which constraints make the problem hard? What did previous work already achieve? What new idea was tested, how, and with which evidence? Which limitations remain? For future work, separate established observations from testable hypotheses.

## Useful default chains, not fixed slide templates
- Experimental paper: task/object -> available inputs and constraints -> existing solution space -> concrete gap -> model inputs/outputs and operations -> datasets and protocol -> main evidence -> ablations and limitations -> conclusion.
- Review: organizing question -> taxonomy -> category evidence -> comparisons and conflicts -> open questions -> synthesis.
- Theory: definitions and setting -> motivating example -> central theorem -> proof intuition and assumptions -> consequences and limits.
- Teaching: learning objective -> worked intuitive example -> formal concept -> practice -> recap.
- Proposal: measurable problem -> prior evidence -> hypothesis -> executable work packages -> controls/metrics -> risk and timeline.

## Per-slide narrative contract
Each substantive slide should have: question/claim, relevance to preceding slide, evidence or explanation, conclusion/boundary, next question, estimated speaking time, and sources. Not every slide needs all blocks on canvas; explanation belongs partly in notes. Introduce terms on first use. Put metric direction and dataset split before evaluating results.

## Continuous spoken script
Write natural speech that follows figure reading order. Avoid slide-by-slide disconnected abstracts and repetitive 'on the previous slide' fillers. Read the full script consecutively, check term consistency, time, repeated claims and unsupported transitions. Source blocks in notes should use: [Sources] followed by human-readable file + page/figure/table and [/Sources].
